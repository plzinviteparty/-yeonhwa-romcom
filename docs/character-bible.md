## 공통 원화 규칙
여성 캐릭터 이목구비는 사용자가 직접 그린 **2번 참고 이미지**를 핵심 조형 기준으로, 선명한 2D 선화와 단순한 셀 채색을 사용. 반실사 금지. 서로 다른 캐릭터의 설정·눈 색·직업·점·헤어스타일 혼합 금지. 표정과 시선, 포즈는 성격에 따라 다르게. 캐릭터 시트는 디자인 원본, 실제 게임용 투명 스탠딩·표정 차분·SD·CG는 별도 리소스.
